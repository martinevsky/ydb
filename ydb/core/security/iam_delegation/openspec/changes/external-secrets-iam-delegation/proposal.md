# Delegated token acquisition

## Why

Own shared platform-authenticated minting, refresh, strict token usability and the producer budget that secret readers must honor. The contract belongs beside the implementation so changes to this component can be reviewed with their acceptance criteria.

## What Changes

- Specify the restored behavior and remaining hardening work owned by this component.
- Preserve the existing authentication, immutable identity and recovery guarantees.
- Track verified work separately from pending regression fixes in `tasks.md`.

## Capabilities

### New Capabilities

- `iam-delegated-token-acquisition`: Own shared platform-authenticated minting, refresh, strict token usability and the producer budget that secret readers must honor.

### Modified Capabilities

None. This is the initial OpenSpec contract for this component.
